# Getting Started with Vortex of Enlightenment

Welcome to your journey through the Vortex of Enlightenment! This guide will help you take your first steps into this mystical text-based experience.

## Prerequisites

- Python 3.8 or higher
- pip package manager
- Terminal with UTF-8 support

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/vortex.git
cd vortex
```

2. Create a virtual environment (recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows, use: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

## Your First Journey

1. **Launch the Application**
```bash
python main.py
```

2. **Complete the Initial Questionnaire**
- The Voight-Kampff questionnaire will assess your starting profile
- Answer honestly - there are no "right" answers
- Your responses shape your unique journey

3. **Understanding the Interface**
- Use arrow keys to navigate
- Press Enter to select options
- Press 'H' for help at any time
- Press 'Q' to save and quit

4. **The Pond System**
- Start at your assigned pond based on your profile
- Each pond offers unique challenges and teachings
- Complete challenges to unlock new streams
- Build connections between ponds through the stream system

5. **Working with Guides**
- Each pond has a unique guide
- Guides adapt to your interaction style
- Ask questions to deepen your understanding
- Learn from their cultural perspectives

## Basic Commands

- `help` - Display available commands
- `status` - View your current progress
- `map` - Display pond connections
- `guide` - Interact with your current guide
- `challenge` - Start a new challenge
- `meditate` - Reflect on your journey
- `profile` - View your profile dimensions

## Tips for Success

1. **Embrace the Journey**
   - Take your time exploring each pond
   - There's no "right" way to progress
   - Each interaction shapes your experience

2. **Engage with Guides**
   - Build relationships with your guides
   - Ask questions about their traditions
   - Learn from their unique perspectives

3. **Balance Your Progress**
   - Work on all profile dimensions
   - Connect teachings across ponds

4. **Track Your Growth**
   - Review your profile regularly
   - Notice pattern connections
