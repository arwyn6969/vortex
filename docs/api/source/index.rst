Project Overview
--------------

VORTEX is built with a focus on modularity, extensibility, and clean architecture. The system is designed
around several key components:

* **Game Engine**: Core game logic and state management
* **Player Management**: Player profiles and progression tracking
* **Guide System**: AI-powered interactive guides
* **Location System**: Dynamic world navigation
* **Dialogue System**: Natural language processing and response generation
