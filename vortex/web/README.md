# Playable lattice (web kernel)

TypeScript tables used by the living web session. They must agree with:

- `vortex/src/mythology/paths.py` (22 streams + meanings)
- `vortex/src/mythology/veils.py` (Crown, Qoph)
- `vortex/src/mythology/correspondences.py` (ponds, guides, permissions)

Files:

- `paths.ts` — Aleph through Tav, with meanings revealed on a second walk
- `lattice.ts` — ten ponds, undirected edges including Qoph, `streamStatus` veils

The Grok-hosted session is the current playable face. This folder is the kernel so the Python CLI and the web game do not drift.
