## Interface Overview

### Terminal Display
```
+------------------------+
|     Vortex Status     | <- System status bar
+------------------------+
|                       |
|    Main Display       | <- Content area
|                       |
+------------------------+
| > command_prompt      | <- Command input
+------------------------+
```

### Display Elements
- **Status Bar**: Shows current location, energy levels, and active effects
- **Content Area**: Displays challenges, teachings, and interactions
- **Command Prompt**: Input area for commands and responses

### Color Coding
- **Gold**: Wisdom-related content
- **Blue**: Kindness-related content
- **Red**: Expression-related content
- **Green**: Boundary-related content
- **Purple**: Understanding-related content
- **White**: Harmony-related content

## Navigation System

### Basic Movement
```bash
# Enter a pond
enter wisdom

# Return to previous location
back

# View available paths
map

# Quick travel to Central Hub
hub
```

### Location Types
1. **Central Hub**
   - Starting point
   - Access to all ponds
   - Profile overview
   - System announcements

2. **Pond Spaces**
   - Challenge areas
   - Teaching zones
   - Meditation spots
   - Integration points

3. **Transition Paths**
   - Energy streams
   - Connection points
   - Wisdom bridges

### Navigation Tips
- Use `map` frequently to orient yourself
- Check energy levels before entering new areas
- Note connection points between ponds
- Mark favorite locations with `bookmark`
